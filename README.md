# Waveshare_ESP32-S3-TOUCH-LCD-4
ESPHome config and board docs for the Waveshare_ESP32-S3-TOUCH-LCD-4 (rev. 4.0 currently)


Tested working configs for the Waveshare ESP32-S3-TOUCH-LCD-4 boards in ESPHome.
Initially published for the revision 4.0 board but I welcome submissions for previous revisions (including any hardware mods as required for some previous revs.).
The rev4 config currently references one unmerged PR to support the Waveshare custom
IO expander, will update this repo when that is merged.

Docs folder holds PDFs for the various chips on this board and the board overview PDFs as well.
Included the vendorfw file(s) to allow verification of properly functioning hardware if anyone is troubleshooting.
Let me know if any relevant docs or info is missing please and I'll get this updated.
